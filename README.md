### **Reto Frontend: Rimac Seguro Salud Flexible**

Este proyecto es un **reto de desarrollo frontend** que consiste en una aplicación web construida con **React** y un sistema de enrutamiento. La aplicación guía al usuario a través de un flujo de tres vistas principales:

1.  **Formulario de Ingreso**: Una vista inicial con un formulario para capturar y validar la información del usuario, como nombre, apellido, DNI y teléfono.
2.  **Selección de Plan**: Una vista donde el usuario puede elegir entre diferentes planes disponibles. Los datos de estos planes se obtienen de una API externa.
3.  **Resumen de la Compra**: Una vista final que muestra un resumen detallado del plan seleccionado.

La aplicación está diseñada para ser **completamente responsiva**, adaptándose a diferentes tamaños de pantalla, y utiliza **Sass** para una gestión modular de los estilos. Además, se implementó el uso de **`localStorage`** para mantener la persistencia de los datos del usuario durante la navegación.
